# Agent Router 自动签到工具操作手册

## 1. 工具说明

本工具通过 Windows 自带的“任务计划程序”每天自动运行浏览器脚本：

1. 清理 `https://ps.air-outer.com` 的旧登录状态。
2. 复用用户自己的 GitHub 登录状态完成 OAuth 登录。
3. 通过登录触发 Agent Router 每日签到。
4. 将运行结果和错误日志保存到本机 SQLite 数据库。

程序不是常驻服务。它只在 Windows 用户登录时或每天 09:00 启动，完成后自动退出。同一天成功签到后，后续触发会直接跳过。

## 2. 系统要求

- Windows 10 或 Windows 11
- Google Chrome
- Node.js 22 或更高版本
- 可以正常访问 GitHub 和 `https://ps.air-outer.com`
- 一个可用于 Agent Router 登录的 GitHub 账号

检查 Node.js 版本：

```powershell
node --version
```

如果显示的主版本低于 `22`，请先升级 Node.js。

## 3. 获取并安装程序

将整个项目文件夹复制或解压到一个长期保留的位置，例如：

```text
D:\Tools\AgentPunch
```

不要把程序放在临时目录、下载缓存目录或之后会被删除的位置。

打开 PowerShell，进入项目目录：

```powershell
cd D:\Tools\AgentPunch
```

安装依赖：

```powershell
npm install
```

检查运行环境：

```powershell
npm run doctor
```

命令正常输出 Node.js 版本、数据目录和数据库路径，即表示基础环境可用。

## 4. 首次绑定自己的 GitHub 账号

每位用户必须在自己的电脑和 Windows 账户中执行一次初始化：

```powershell
npm run setup
```

操作步骤：

1. 程序会打开一个独立的 Chrome 窗口。
2. 在窗口中登录自己的 GitHub 账号。
3. 使用自己的认证器、GitHub Mobile 或密码管理器完成 2FA。
4. 确认 GitHub 已登录后，回到 PowerShell。
5. 按 Enter 继续。
6. 程序会立即执行一次 Agent Router 登录签到验证。

成功时会显示：

```text
签到成功，新增额度已到账
```

GitHub 登录状态会保存在当前 Windows 用户的独立 Chrome 配置中。程序不会把 GitHub 密码或 2FA 密钥保存到 SQLite 或项目文件中。

> 不要把 2FA 密钥输入第三方验证码网站。请使用可信认证器在本机生成验证码。

## 5. 安装每日自动任务

首次绑定并验证成功后运行：

```powershell
npm run install-task
```

该命令会创建 Windows 计划任务：

```text
AgentRouterDailyCheckin
```

计划任务包含两个触发器：

- 当前 Windows 用户登录时运行。
- 每天 09:00 运行。

如果电脑在 09:00 关机，Windows 会在下次满足运行条件时尽快补运行。SQLite 会检查当天是否已经成功，避免重复签到。

## 6. 日常使用

安装计划任务后无需每天手动操作，也不需要保持 PowerShell 窗口打开。

电脑需要满足以下条件：

- 已开机并登录安装计划任务的 Windows 账户。
- 网络能够访问 GitHub 和 `ps.air-outer.com`。
- GitHub 登录状态仍然有效。

自动化会截获原本指向 `agentrouter.org` 的 OAuth 回调并改投到 `ps.air-outer.com`，因此日常签到不要求访问主域名。

## 7. 手动签到

需要立即执行时，在项目目录运行：

```powershell
npm run run
```

如果当天已经成功，会显示：

```text
YYYY-MM-DD 已成功执行过，跳过。
```

这属于正常行为。

仅在排错时强制忽略当天成功记录：

```powershell
$env:AGENT_ROUTER_FORCE='true'
npm run run
Remove-Item Env:AGENT_ROUTER_FORCE
```

## 8. 查看运行状态和日志

查看最近的运行记录：

```powershell
npm run doctor
```

默认数据目录：

```text
%LOCALAPPDATA%\AgentRouterCheckin
```

主要文件：

```text
checkin.sqlite3       SQLite 运行记录和日志
browser-profile\     当前用户的独立 GitHub 浏览器登录状态
```

请勿把 `browser-profile`、SQLite 数据库或整个数据目录发送给其他人。

## 9. 查看 Windows 计划任务

打开 Windows 开始菜单，搜索并打开“任务计划程序”，在“任务计划程序库”中找到：

```text
AgentRouterDailyCheckin
```

也可以在 PowerShell 中查看：

```powershell
Get-ScheduledTask -TaskName AgentRouterDailyCheckin
Get-ScheduledTaskInfo -TaskName AgentRouterDailyCheckin
```

`LastTaskResult` 为 `0` 通常表示最近一次运行成功。

## 10. GitHub 登录状态失效

如果运行时显示：

```text
GitHub 登录态已失效，请运行 npm run setup 重新登录
```

进入项目目录并重新初始化：

```powershell
npm run setup
```

常见失效原因包括：

- 修改了 GitHub 密码。
- 重置了 GitHub 2FA。
- 在 GitHub 安全设置中注销了其他会话。
- GitHub 主动要求重新验证设备。
- 浏览器数据目录被清理或迁移。

## 11. 常见故障

### 11.1 `node` 或 `npm` 不是命令

Node.js 未安装或没有加入 PATH。安装 Node.js 22+ 后重新打开 PowerShell。

### 11.2 找不到 Chrome

安装正式版 Google Chrome，然后重新运行：

```powershell
npm run setup
```

### 11.3 网络连接中断

站点偶尔可能出现 `ERR_CONNECTION_CLOSED`。程序会自动有限重试；如果仍失败，可稍后手动运行：

```powershell
npm run run
```

失败不会被记为当天成功，因此后续计划任务仍可继续尝试。

### 11.4 计划任务没有运行

重新安装任务：

```powershell
npm run install-task
```

然后检查：

```powershell
Get-ScheduledTaskInfo -TaskName AgentRouterDailyCheckin
```

计划任务以当前 Windows 用户的交互登录身份运行。用户未登录时不会启动浏览器自动化。

### 11.5 同一台电脑有多个 Windows 用户

每个 Windows 用户的数据目录和 GitHub 浏览器登录状态是独立的。不过当前计划任务名称固定为 `AgentRouterDailyCheckin`，同一台电脑上的另一位 Windows 用户再次安装时可能覆盖原任务。

建议每台电脑只由一个 Windows 用户安装；如需多用户并存，应为每位用户设置不同的计划任务名称。

## 12. 更新程序

替换或拉取新的项目代码后，在项目目录执行：

```powershell
npm install
npm test
npm run doctor
```

如果项目目录位置没有改变，一般不需要重新安装计划任务。如果移动了项目文件夹，必须重新运行：

```powershell
npm run install-task
```

## 13. 卸载

先删除 Windows 计划任务：

```powershell
npm run uninstall-task
```

然后可以删除项目目录。

如需同时删除本机登录状态、数据库和日志：

```powershell
Remove-Item -LiteralPath "$env:LOCALAPPDATA\AgentRouterCheckin" -Recurse -Force
```

删除数据目录后，再次使用必须重新运行 `npm run setup`。

## 14. 给其他用户分发

可以分发项目源码或压缩包，但不要包含：

- `node_modules\`
- `.env`
- `%LOCALAPPDATA%\AgentRouterCheckin\`
- `browser-profile\`
- `checkin.sqlite3`
- 任何 GitHub 密码、Cookie、2FA 种子或验证码

其他用户收到项目后，依次运行：

```powershell
npm install
npm run doctor
npm run setup
npm run install-task
```

每位用户都应登录自己的 GitHub 账号，不能复制其他人的浏览器登录数据。
